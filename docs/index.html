Desafio: Evita a exceção IllegalStateException: OffsetMapping.originalToTransformed ao limitar e mapear o cursor bidirecional no 5º dígito do CEP. core/util 
class CepVisualTransformation : VisualTransformation {
    override fun filter(text: AnnotatedString): TransformedText {
        val digits = text.text.filter { it.isDigit() }.take(8)
        val out = buildString {
            for (i in digits.indices) {
                append(digits[i])
                if (i == 4 && digits.length > 5) append('-')
            }
        }

        val offsetMapping = object : OffsetMapping {
            override fun originalToTransformed(offset: Int): Int {
                val clamped = offset.coerceIn(0, digits.length)
                return if (clamped <= 5) clamped else (clamped + 1).coerceAtMost(out.length)
            }

            override fun transformedToOriginal(offset: Int): Int {
                val clamped = offset.coerceIn(0, out.length)
                return if (clamped <= 5) clamped else (clamped - 1).coerceAtMost(digits.length)
            }
        }

        return TransformedText(AnnotatedString(out), offsetMapping)
    }
}

Desafio: Consumo reativo da API do ViaCEP com coroutines em background (Dispatchers.IO) e postagem segura na UI. features/enderecos 
fun buscarCep(cepNumeros: String, onResultado: (DadosEnderecoCep?) -> Unit) {
    val cepLimpo = cepNumeros.filter { it.isDigit() }
    if (cepLimpo.length != 8) return

    viewModelScope.launch(Dispatchers.IO) {
        _carregandoCep.value = true
        val dados = runCatching {
            val response = viaCepService.buscarEndereco(cepLimpo)
            if (response.erro == true) null else {
                DadosEnderecoCep(
                    logradouro = response.logradouro.orEmpty(),
                    bairro = response.bairro.orEmpty(),
                    cidade = response.localidade.orEmpty(),
                    estado = response.uf.orEmpty().uppercase()
                )
            }
        }.getOrNull()

        withContext(Dispatchers.Main) {
            _carregandoCep.value = false
            onResultado(dados)
        }
    }
}
Desafio: Múltiplas sessões ativas no dispositivo via flatMapLatest ligado ao DataStore, prevenindo vazamento de histórico. features/historico 
@OptIn(ExperimentalCoroutinesApi::class)
class HistoricoViewModel(
    private val repository: PedidoRepository,
    sessionManager: SessionManager
) : ViewModel() {

    // E-mail reativo sincronizado com o DataStore
    private val emailUsuario: StateFlow = sessionManager.usuarioEmailFlow
        .map { it ?: AppConstants.DEFAULT_USER_EMAIL }
        .stateIn(viewModelScope, SharingStarted.Eagerly, AppConstants.DEFAULT_USER_EMAIL)

    // Reconecta à query do Room instantaneamente quando o usuário logado muda
    val pedidos: StateFlow> = emailUsuario
        .flatMapLatest { email -> repository.obterPedidosPorUsuario(email) }
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), emptyList())

    fun confirmarEntregaItem(pedidoId: Int, produtoId: Int) {
        viewModelScope.launch(Dispatchers.IO) {
            runCatching { repository.confirmarEntregaItem(pedidoId, produtoId) }
        }
    }
}

Pipeline e Fluxo de Dados

1

Camada de Apresentação

Desenvolvida integralmente em Jetpack Compose. Gerencia estados imutáveis via StateFlow e captura eventos do usuário desacoplados dos ciclos de vida da Activity.

2

Camada de Domínio & Sessão

Injeção dinâmica provida pelo Koin. O SessionManager (Jetpack DataStore) emite credenciais criptografadas para isolamento multi-tenant local.

3

Persistência & Rede

Room Database com operações assíncronas em Coroutines e consumo de REST APIs (FakeStore e ViaCEP) por meio do Retrofit 2 e serialização Gson.
